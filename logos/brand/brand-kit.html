● Halite Brand Kit
Three mark families, two lockups each, full PNG size set

Marks

Three distinct icon families, each tuned for a different role. All use the Halite amber palette; pick the mark that best fits the context.

The Lattice

3×3 grid mark. The most semantically dense — diagrams both halite's atomic lattice and the SaltStack master+minion topology. Default choice for the app icon.

The Salt Cube

Single isometric cube, tri-tone amber. The most iconic and merchandise-friendly. Use for marketing, decals, swag, splash screens.

The Triple Stack

Three cubes piled in a triangular cluster. Compact and sculptural. Works well as a section divider or small accent.

Horizontal Lockups

Icon + wordmark side-by-side. Use these in topbars, email signatures, README headers.

Stacked Lockups

Icon centered above the wordmark. Use these for hero blocks, login screens, splash pages.

Monochrome & Wordmark-only

For single-color contexts (foil stamping, embroidery, amber-on-amber). The Cube's tri-tone story requires its own mono wireframe variant; Lattice and Stack already render in a single color.

Cube · Mono Wireframe

Same hex silhouette + internal Y, single-stroke amber. Reads as a cube down to ~64px.

Wordmark

"halite" set in Inter Semibold, slightly tracked tight. Use standalone when the mark is established by adjacent context.
