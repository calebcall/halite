# Halite Brand Kit

Three mark families + a shared wordmark, in both vector and raster.

Open `brand-kit.html` in a browser for the full visual showcase.

## Quick reference — which mark when?

| Mark              | Best for                                                                 |
| ----------------- | ------------------------------------------------------------------------ |
| **The Lattice**   | App icon, favicon, anywhere the mark needs to imply structure/topology   |
| **The Salt Cube** | Marketing, splash screens, merchandise, anywhere needing a hero visual   |
| **The Triple Stack** | Section dividers, accents, secondary illustrative uses               |

Each mark ships in two layout variants:

- `lockup-horizontal.svg` — icon + wordmark side-by-side (use in headers, signatures)
- `lockup-stacked.svg` — icon above wordmark (use in hero blocks, login screens)

And the `wordmark/halite.svg` is the bare wordmark with no icon.

## Colors

The brand is built on one signature color — **Halite Amber `#e5a00d`** (HSL `41° 89% 47%`). Two
supporting tones (`#f5b938` lighter, `#a77100` darker) appear only in the Salt Cube's tri-tone
faces and as light/dark state variants.

Surfaces are intentionally dark — the brand reads against deep neutrals (`#0e0e0e` through
`#2a2a2a`), inspired by Plex's media console aesthetic. Light-mode use is supported but the
mark is at its strongest on dark.

All values are documented in `tokens/colors.css` (consume directly in CSS) and `tokens/colors.json`
(W3C Design Tokens format — feeds Figma, Style Dictionary, etc.).

## Typography

The wordmark sets **"halite"** in lowercase, **Inter Semibold (600)**, with `-0.015em`
letter-spacing. Inter is also the app's body font, so the wordmark feels native everywhere it
appears.

> **Important:** PNG exports of the wordmark and the lockups assume Inter is installed locally.
> If the rasterizer can't find Inter it'll fall back to a system sans-serif and the
> letterforms will look subtly different. The SVG files include a fallback stack
> (`'Inter', ui-sans-serif, system-ui, …`), so browser rendering degrades gracefully.

## Clear space & minimum size

- **Clear space**: maintain padding around any mark equal to the height of the wordmark's
  x-height (or, for icon-only marks, equal to one full lattice grid cell — roughly 1/9 of the
  mark's visual height).
- **Minimum size**:
  - Lattice: 24px (collapses to a punchy `+` of dots at this size)
  - Cube: 16px (holds its 3D form remarkably well — preferred for favicons)
  - Stack: 32px (below this the three cubes start to blur together)
  - Wordmark alone: 96px wide (smaller than this and "halite" loses its character)

## Re-exporting PNGs

The PNGs were generated by `/tmp/halite-export.mjs` using the [`sharp`](https://sharp.pixelplumbing.com/)
npm package. To regenerate (e.g. after editing an SVG):

```bash
cd /tmp && node halite-export.mjs
```

If you have the skill's `export.sh` script available, that's equivalent and produces the same
size set.
